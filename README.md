## ?? Конфиденциально

## ?? О приложении

SHome-GEO — бесплатное приложение для отправки GPS-координат
телефона в SHome (планшет) через Mail.ru Cloud.

## ?? Возможности

- Отправка GPS-координат
- Работа в фоне (Foreground Service)
- Автозапуск при перезагрузке
- Интеграция с Mail.ru Cloud
